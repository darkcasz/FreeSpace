FreeSpace 0.3.0 para Windows x64.

- Búsqueda automática de actualizaciones al iniciar y cada cuatro horas.
- Descarga en segundo plano desde GitHub Releases.
- Instalación al cerrar FreeSpace o con el botón Reiniciar e instalar.
- La instalación manual de una actualización espera a que termine el análisis o mantenimiento.
- Conserva el análisis de discos y las herramientas de limpieza de WinSxS y temporales.

Para activar las actualizaciones, instala esta versión una vez. Las versiones 0.1 y 0.2 no incluyen actualizador.
